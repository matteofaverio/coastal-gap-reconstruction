# Figures

All figures in this directory are generated by
`scripts/generate_public_figures.py` from the public data and results
tables in this repository.

Run from the `public_export/` directory:

```bash
python scripts/generate_public_figures.py
```

---

## chlorophyll/

| Figure filename | Built from | Purpose | Evidence tier |
|---|---|---|---|
| `figure_target_record_and_missingness.png` | `data_public/chlorophyll/chlorophyll_daily_target.csv`, `data_public/chlorophyll/chlorophyll_real_gap_inventory.csv` | Overview of the 11-year daily chlorophyll-a record, showing observed values and all real gaps | Descriptive — target/missingness |
| `figure_method_benchmark_summary.png` | `results_public/chlorophyll/chlorophyll_benchmark_summary.csv` | Forest plot comparing the leading method (TS-ICL satellite-proxy) against all comparators; shows delta-MAE with 95% bootstrap confidence intervals | Validation-grade artificial-gap evidence |
| `figure_gap_length_performance.png` | `results_public/chlorophyll/chlorophyll_artificial_gap_scores.csv` | Line plot of reconstruction error (day-weighted MAE) by gap length for four methods, from 1 to 60 days | Validation-grade artificial-gap evidence |
| `figure_event_limitation.png` | `results_public/chlorophyll/chlorophyll_event_performance_summary.csv` | Lollipop chart showing the event penalty (event-day MAE minus non-event-day MAE) for every evaluated method; illustrates that all methods under-predict on high-chlorophyll days | Event/high-Chl limitation (artificial gaps) |
| `figure_real_gap_candidate_example.png` | `results_public/chlorophyll/chlorophyll_real_gap_candidate_outputs_daily.csv` | Example time window showing observed chlorophyll alongside candidate reconstructions for a real gap; candidate values have no withheld ground truth | Plausibility-only candidate output |

---

**Note on evidence tiers:** See `docs/evidence_hierarchy.md` for a full
description of what each evidence tier means and how to interpret figures
in each category. In particular, "Plausibility-only candidate output"
figures should not be used to claim that one method is more accurate than
another — only artificial-gap validation results carry that weight.

## oxygen/

Unlike the chlorophyll figures above, these are **not** generated by
`scripts/generate_public_figures.py` — they are reproduced directly from
the published report (`manuscript/report/figures/` in the private repository), which
uses report-specific multi-panel layouts. They are included here as static
assets so the oxygen case study has figures without duplicating that
paneling logic in the public script.

| Figure filename | Source (private repo) | Purpose | Evidence tier |
|---|---|---|---|
| `figure_oxygen_target_record_and_missingness.pdf/.png` | `manuscript/report/figures/fig_oxygen_target_and_gaps.pdf` | Daily dissolved-oxygen record and real-gap inventory | Descriptive — target/missingness |
| `figure_oxygen_distribution.pdf/.png` | `manuscript/report/figures/fig_oxygen_distribution.pdf` | Empirical distribution of daily mean oxygen | Descriptive |
| `figure_oxygen_benchmark_summary.pdf` | `manuscript/report/figures/fig_oxygen_benchmark_primary_v3.pdf` | Error by gap length (Panel A) and paired MAE differences vs. TS-ICL physical covariates (Panel B), oxygen artificial-gap pool | Validation-grade artificial-gap evidence |
| `figure_oxygen_tail_diagnostics.pdf` | `manuscript/report/figures/fig_oxygen_tail_diagnostics_v6.pdf` | Relative improvement by distribution quantile band, and tail-persistence diagnostic | Validation-grade artificial-gap evidence (distribution-conditional) |

See `results_public/oxygen/` for the underlying tables and
`notebooks/10_oxygen_case_study.ipynb` for a runnable walkthrough of the
same numbers.
